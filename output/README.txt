OUTPUT FOLDER - Processed Videos
=================================

This folder contains your processed videos with person detection results.

WHAT YOU'LL FIND HERE:
======================
- Videos with person detection bounding boxes
- Confidence scores displayed on detected persons
- Frame counters and statistics overlays
- High-quality processed videos maintaining original resolution

FILE NAMING:
============
If you don't specify an output name, files will be saved as:
- Original: input\meeting.mp4
- Processed: output\meeting_detected.mp4

DETECTION FEATURES:
===================
✅ Person bounding boxes (green = high confidence, yellow = medium, orange = low)
✅ Confidence scores (0.00 to 1.00)
✅ Real-time person count
✅ Processing statistics (FPS, frame number, etc.)
✅ GPU-accelerated processing
✅ Original video quality preserved

VIDEO FORMATS:
==============
Processed videos are saved in MP4 format with H.264 encoding for maximum compatibility.

PROCESSING STATS:
=================
After processing, you'll see statistics like:
- Total frames processed
- Processing time
- Average FPS
- Total person detections
- Maximum persons detected in a single frame

These processed videos can be:
- Shared with others
- Used for analysis
- Imported into other video editing software
- Uploaded to platforms that support MP4

The AI detection runs on your NVIDIA GPU for maximum speed and accuracy!
